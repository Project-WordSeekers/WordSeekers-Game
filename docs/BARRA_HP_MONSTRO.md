# Barra de HP do monstro
- A antiga etiqueta textual `EnemyHPLabel` permanece oculta para compatibilidade.
- `EnemyHPHud/EnemyHPBar` mostra uma barra de 3 pontos acima do sprite do monstro.
- Cada acerto reduz o valor em 1, acompanhando o dano existente.
- A barra é reposicionada quando a janela muda de tamanho e fica oculta fora da batalha.
- Nenhuma alteração na lógica de dano, áudio, monstros ou quizzes.
- Validação estrutural do ZIP concluída; testar visualmente no Godot 4.
