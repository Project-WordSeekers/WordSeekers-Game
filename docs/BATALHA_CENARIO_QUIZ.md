# Cena de batalha
Imagem enviada pelo usuário convertida para WebP sem perdas: `assets/environments/shared/battle_landscape.webp`.
Exibida por `CanvasLayer` + `TextureRect` em `KEEP_ASPECT_CENTERED`, mostrando o cenário completo sem recorte; podem existir faixas discretas em telas com proporção diferente.
Interface de quiz em `DialogueUI` é centralizada dinamicamente no viewport, largura máxima 900px, margens de 16px e quebra de linha.
O painel original de batalha permanece oculto pelo script existente. Não alteramos questões nem regras de combate.
Validação: recursos e ZIP; execução no Godot não verificada.
